Featured Projects

Active Directory Implementation & ISO 27001 Preparation

Pronto BPO · Technical Lead · 3-month delivery

Designed and implemented the organization's first production Active Directory infrastructure from the ground up.

Scope

- Designed the initial AD architecture and deployment strategy.
- Built a pilot domain to validate technical feasibility and security requirements.
- Evaluated implementation constraints discovered during the pilot.
- Designed and deployed a clean production domain after identifying domain-rename limitations in the selected Samba AD implementation.
- Configured Domain Controllers, Group Policy, account structures, password policies, and endpoint security controls.
- Implemented BitLocker recovery-key integration with Active Directory.
- Hardened authentication and directory services.
- Integrated endpoint monitoring and security tooling.
- Produced technical and audit-oriented documentation aligned with ISO 27001:2022 preparation.
- Maintained direct technical ownership throughout implementation and stakeholder coordination.

Delivery approach

Assessment → Architecture → Pilot → Validation → Production Deployment → Hardening → Monitoring → Documentation

The project required balancing security requirements, infrastructure limitations, operational continuity, and cost constraints while delivering a production-ready identity platform.

Global SIP — Session Mitigation Framework

Global Service Improvement Project · Approved

Designed and delivered a PowerShell-based automation framework for managing campaign session transitions across Windows endpoints.

The project focused on reducing repetitive manual deployment work and standardizing the installation process for non-technical users.

Engineering highlights

- PowerShell-based automation.
- Multi-method installation engine.
- Automatic fallback across:
  - "winget"
  - MSI
  - EXE
- Automated validation and deployment workflow.
- Packaged as a branded executable for end-user execution.
- Designed for repeatable deployment across multiple campaign environments.

Result: approximately 60% reduction in deployment time.
